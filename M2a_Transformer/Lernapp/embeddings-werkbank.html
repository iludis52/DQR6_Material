Trainierte Gewichte vom anderen Rechner verwenden

Synchronisiere Checkpoints/bestes_modell.pt oder führe den folgenden Export direkt auf dem Trainingsrechner aus. Das Skript liegt neben dem Lehrnotebook und nutzt dieselbe Python-Umgebung.

python exportiere_embeddings.py Checkpoints/bestes_modell.pt

Öffne danach die erzeugte Data/embeddings-checkpoint.json über „Checkpoint-Export laden“. Sie enthält beide Embeddingtabellen, die erste LayerNorm und den zum Checkpoint gehörenden Tokenizer. Ein separates tokenizer.json wird dafür nicht benötigt. Die große .pt-Datei bleibt außerhalb des Browsers.

Bei Nutzung über einen lokalen Webserver wird der Export automatisch aus ../Data/embeddings-checkpoint.json geladen. Ohne Export wird ../Data/tokenizer.json für die Tokenisierung verwendet. Beim direkten Öffnen der HTML-Datei wähle die JSON-Datei über die Schaltfläche aus. Alle Berechnungen bleiben lokal.

Die Positionen zählen Tokens ab 0, nicht Wörter oder Buchstaben. Es werden keine Sondertokens automatisch ergänzt; das Chat-Beispiel enthält sie ausdrücklich.

02

Das Token-Embedding E[ID]

gelernt

Die ID wählt eine ganze Zeile aus tok_emb.weight. Dasselbe Token hat an jeder Position denselben Ausgangsvektor. Einzelnen Dimensionen sind hier keine festen Begriffe wie „Farbe“ oder „Bedeutung“ zugewiesen.

＋
03

Das Positions-Embedding P[Position]

gelernt

GuppyLM nutzt gelernte Positions-Embeddings aus pos_emb.weight, keine Sinus-/Kosinusformel. An Position 0 wird Zeile 0 gelesen, an Position 1 Zeile 1 usw. Die Positionsvektoren hängen von der Position ab, nicht von der Token-ID.

＝
04

Token + Position

berechnet

Komponentenweise Addition: x[t, d] = E[IDₜ, d] + P[t, d]. Die Dimension bleibt erhalten. Wir rechnen wie bei modell.eval(): Das Dropout nach der Addition ist ausgeschaltet. Diese Summe geht auch unverändert in den ersten Residualpfad.

↓
05

Die erste LayerNorm

Pro Token über alle Modelldimensionen normalisieren, danach trainierte Skalierung γ und Verschiebung β anwenden.

berechnet + gelernt

Hier wird blocks.0.norm1 aus dem Checkpoint verwendet. Ihr Ausgang geht zu den Q/K/V-Projektionen von Block 1. γ und β sind trainiert: Der Ausgang muss daher weder Mittelwert 0 noch Varianz 1 haben.
